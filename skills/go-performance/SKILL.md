# Производительность Go
## Метод
Сначала установи метрику: ns/op, B/op, allocs/op, latency или throughput. Получи baseline. Исследуй профиль конкретного пакета. Оптимизируй один фактор и повтори измерение при тех же условиях.
```bash
go test -run='^$' -bench=. -benchmem -count=5 ./...
go test -run='^$' -bench=. -cpuprofile=cpu.out ./internal/example
go tool pprof cpu.out
```
Путь internal/example замени существующим пакетом.
Не делай вывод из одного прогона. Не заменяй читаемый код на unsafe, pooling или ручное управление памятью без доказанной пользы. Проверь корректность и гонки после оптимизации.
## Отчет
Приведи окружение, команды, результаты до/после и ограничения. Если измерить нельзя, маркируй предположение.
