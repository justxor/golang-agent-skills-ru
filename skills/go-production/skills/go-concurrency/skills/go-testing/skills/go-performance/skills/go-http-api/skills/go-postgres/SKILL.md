# PostgreSQL в Go
1. Изучи схему, ограничения, индексы и границы транзакций.
2. Используй параметры SQL, QueryContext/ExecContext и проверяй errors.Is(err, sql.ErrNoRows).
3. Закрывай rows; после обхода проверяй rows.Err().
4. sql.DB — общий пул. Настрой лимиты по бюджету соединений и числу экземпляров.
5. Проверь ошибки BeginTx, запроса и Commit. Выполни defer tx.Rollback().
6. Не держи транзакцию во время обращения к независимому удаленному сервису.
## Приемка
Тесты на commit/rollback, конфликт уникальности, отмену и пустой результат. Для миграций отдельно оцени совместимость приложения до/после релиза; не исполняй миграции в production без явного разрешения.
