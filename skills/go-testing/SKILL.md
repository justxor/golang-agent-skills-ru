# Тестирование Golang
1. Определи проверяемый контракт, типичные и граничные значения.
2. Добавь регрессионный тест перед исправлением ошибки.
3. Используй t.Run для именованных случаев, t.Helper для помощников, t.Cleanup для ресурсов.
4. Проверяй наблюдаемое поведение, не внутренние вызовы без необходимости.
5. Для HTTP используй httptest.NewRecorder и httptest.NewRequest.
6. Для SQL-поведения используй изолированную тестовую базу, не production.
## Команды
```bash
go test ./...
go test -race ./...
go test -cover ./...
```
Не заявляй о прохождении команд, если они не запускались. Опиши причины flaky-теста и устрани зависимость от времени, порядка исполнения и общего состояния.
